12-Week Curriculum

Module
Topics Covered
Module 1
Python Programming
Python fundamentals, variables, data types, operators, conditions, loops, functions, data structures and practical coding.
Module 2
NumPy & Pandas
Arrays, indexing, slicing, NumPy operations, Series, DataFrames and data manipulation.
Module 3
Data Cleaning
Missing values, duplicates, data types, outliers and data quality.
Module 4
Statistics
Descriptive statistics, probability, distributions, correlation and statistical concepts for Data Science.
Module 5
Exploratory Data Analysis
EDA workflow, univariate and bivariate analysis, patterns, relationships and data-driven insights.
Module 6
Data Visualization
Charts, plots, visual storytelling, Matplotlib, Seaborn and effective presentation of insights.
Module 7
Machine Learning Fundamentals
Machine Learning workflow, supervised learning, unsupervised learning, training and testing.
Module 8
Regression
Linear Regression, model building, prediction and evaluation.
Module 9
Classification
Logistic Regression, Decision Trees, Random Forest and classification evaluation.
Module 10
Feature Engineering
Feature selection, transformation, encoding, scaling and improving model performance.
Module 11
Unsupervised Learning
Clustering, customer segmentation and practical unsupervised learning.
Module 12
End-to-End ML Project
Complete project workflow from business problem to data preparation, modelling, evaluation and presentation.
