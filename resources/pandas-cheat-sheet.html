Pandas Cheat Sheet

Quick reference for data manipulation using Pandas.

Import & Read Data

import pandas as pd
df = pd.read_csv("data.csv")
df = pd.read_excel("data.xlsx")

Inspect Data

df.head()
df.tail()
df.shape
df.columns
df.info()
df.describe()

Select & Filter

df["Salary"]
df[["Name", "Salary"]]
df[df["Age"] > 30]
df[(df["Age"] > 30) & (df["Department"] == "IT")]

Missing Values

df.isnull().sum()
df.dropna()
df["Salary"] = df["Salary"].fillna(df["Salary"].mean())

GroupBy

df.groupby("Department")["Salary"].mean()
df.groupby("Department").agg({"Salary":"mean","Age":"max"})

Merge

result = pd.merge(customers, orders, on="Customer_ID", how="inner")

Useful Methods

value_counts(), nunique(), unique(), drop_duplicates(), rename(), astype(), replace().
